# MEP LAB Academy — منصة الكورسات

موقع كورسات كامل بعربي وإنجليزي:
حسابات طلبة، كورسات، دفع يدوي (InstaPay / فودافون كاش + صورة التحويل)، لوحة طالب فيها كود التفعيل، ولوحة أدمن تقبل وترفض الطلبات وتدير الكورسات.
كله **مجاني**: Next.js + Supabase + Vercel.

---

## 1) قاعدة البيانات — Supabase (حوالي 5 دقايق)

1. ادخل على https://supabase.com واعمل حساب، وبعدين **New project** (اختار منطقة قريبة زي Frankfurt).
2. من **SQL Editor ← New query**: الصق محتوى `supabase/schema.sql` كله واضغط **Run**.
3. من **Project Settings ← API** خد:
   - `Project URL`
   - `anon public key`
4. من **Authentication ← URL Configuration**:
   - Site URL = رابط موقعك (هتعرفه في الخطوة 3)
   - Redirect URLs: ضيف `https://YOUR-SITE/auth/callback`
5. (اختياري) **تسجيل الدخول بجوجل**: Authentication ← Providers ← Google، واتبع الخطوات اللي هناك.
6. (اختياري) لو مش عايز تأكيد بالإيميل: Authentication ← Providers ← Email ← اقفل "Confirm email".

## 2) الكود على GitHub

1. اعمل Repository جديد على GitHub (Private عادي).
2. ارفع الفولدر ده كله عليه **من غير** `node_modules` و `.env.local`.

## 3) الرفع على Vercel (مجاني)

1. ادخل https://vercel.com بحساب GitHub، وبعدين **Add New ← Project** واختار الـ repo.
2. في **Environment Variables** ضيف كل المتغيرات اللي في `.env.example` بقيمك الحقيقية:

| المتغير | القيمة |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | من Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | من Supabase |
| `NEXT_PUBLIC_SITE_URL` | رابط الموقع، مثلًا `https://meplab.vercel.app` |
| `NEXT_PUBLIC_INSTAPAY_HANDLE` | عنوان InstaPay بتاعك |
| `NEXT_PUBLIC_VODAFONE_CASH_NUMBER` | رقم فودافون كاش |
| `NEXT_PUBLIC_WHATSAPP` | `2010XXXXXXXX` |
| `NEXT_PUBLIC_FACEBOOK_URL` | `https://facebook.com/MEPLAB.EGY` |
| `NEXT_PUBLIC_PLAYER_DOWNLOAD_URL` | رابط تحميل MEP LAB Player |
| `NEXT_PUBLIC_PLAYER_VERSION` | `1.3.0` |
| `LICENSE_SECRET` | سر طويل عشوائي — **ما تنشروش أبدًا** |
| `JOOBLE_API_KEY` | مفتاح Jooble (قسم الوظايف) |
| `RAPIDAPI_KEY` | اختياري — JSearch |
| `SUPABASE_SERVICE_ROLE_KEY` | من Supabase — سري |
| `CRON_SECRET` | قيمة عشوائية طويلة |
| `GEMINI_API_KEY` | مفتاح Gemini (التقييم بالذكاء الاصطناعي) |
| `GEMINI_MODEL` | `gemini-flash-latest` |
| `GEMINI_FALLBACK_MODEL` | `gemini-flash-lite-latest` |
| `AI_DAILY_LIMIT` | `3` |
| `RESEND_API_KEY` | اختياري — إشعارات الإيميل |
| `EMAIL_FROM` | عنوان الإرسال |
| `ADMIN_EMAIL` | إيميلك لإشعارات الطلبات |

3. اضغط **Deploy**. الموقع هيبقى على `xxx.vercel.app`، وتقدر تربطه بدومين بتاعك بعدين من Settings ← Domains.

## 4) خلّي نفسك أدمن

1. ادخل الموقع واعمل حساب عادي.
2. في Supabase ← SQL Editor شغّل:
   ```sql
   update public.profiles set role = 'admin' where email = 'YOUR@EMAIL.com';
   ```
3. اعمل refresh، وهيظهرلك لينك **الإدارة** فوق.

## 5) قسم الوظايف (أوتوماتيك)

الوظايف بتتجاب كل يوم الساعة 6 الصبح بتوقيت مصر، وبتتخزن في قاعدة البيانات. الزوار بيقروا منها على طول، فمفيش استهلاك للـ API مع كل زيارة.

1. **مفتاح Jooble (مجاني):** ادخل https://jooble.org/api/about واملا الفورم، وهيبعتلك مفتاح. حطه في `JOOBLE_API_KEY`.
2. **(اختياري) JSearch:** بيجيب وظايف من LinkedIn وIndeed وغيرهم. اعمل حساب على RapidAPI، واشترك في الخطة المجانية Basic لـ JSearch، وحط المفتاح في `RAPIDAPI_KEY`. بيشتغل يومين بس في الأسبوع علشان يفضل جوه الحصة المجانية.
3. من Supabase ← Project Settings ← API، خد الـ `service_role` key وحطه في `SUPABASE_SERVICE_ROLE_KEY`. **سري، ما تنشروش.**
4. حط أي قيمة عشوائية طويلة في `CRON_SECRET`. Vercel بيستخدمها لوحده علشان يشغّل التحديث اليومي (ملف `vercel.json`).
5. لو كنت شغّلت `schema.sql` قبل كده، شغّل جزء **Jobs** اللي في آخره بس.
6. أول مرة: ادخل **الإدارة ← إدارة الوظايف ← تحديث الوظايف دلوقتي**.

من نفس الصفحة تقدر كمان تضيف وظيفة بإيدك، أو تخفي وظيفة، أو تمسحها.
الكلمات اللي بيتدوّر بيها لكل تخصص موجودة في `lib/cv/data.ts` (الحقل `q`).

## 6) فحص الـ CV

- الصفحة `/cv-check` بتحلل الـ CV جوه متصفح الزائر، فالملف مش بيترفع على أي سيرفر.
- الأدوار والكلمات المفتاحية ونطاقات المرتبات كلها في `lib/cv/data.ts`. المرتبات تقديرية، فراجعها كل فترة.
- بعد الفحص بتظهر للزائر وظايف من قسم الوظايف مناسبة للدور اللي طلعله.

### التقييم المفصّل بالذكاء الاصطناعي (Gemini)

1. خد مفتاح مجاني من https://aistudio.google.com/apikey وحطه في `GEMINI_API_KEY`.
2. `GEMINI_MODEL`: سيبه `gemini-flash-latest`. لو Google غيّرت اسم الموديل، غيّره من هنا بس.
3. `AI_DAILY_LIMIT`: عدد التقييمات المسموحة لكل حساب في اليوم، والافتراضي 3.
4. لو كنت شغّلت `schema.sql` قبل كده، شغّل جزء **AI CV reviews** اللي في آخره بس.

- التقييم المفصّل للأعضاء بس. الزائر اللي مش داخل بيتحوّل على الدخول، وبعدها بيرجع لنفس الـ CV على طول.
- نص الـ CV بيتبعت لـ Gemini ومش بيتخزن عندنا، وده مكتوب للزائر في الصفحة. اللي بيتخزن بس عدد مرات الاستخدام.
- خطة Gemini المجانية حدودها اليومية صغيرة. لو الموقع كبر، فعّل الـ Billing في Google AI Studio (Flash رخيص جدًا).
- **MEP LAB AI:** المستشار بيقيّم الـ CV على 5 محاور، ويقترح وظايف يقدّم عليها، ويعيد كتابة الـ Summary وأضعف النقاط، ويطلّع المهارات الناقصة مع السبب، و5 أسئلة إنترفيو متوقعة. ولو الطالب لصق إعلان وظيفة، بيطلعله نسبة التوافق وSummary مفصّل على الوظيفة دي.
- **معرفة المجال:** لكل تخصص (المهارات، البرامج، الأكواد، الحاجات اللي بتقلل من الـ CV) ولكل سوق (السعودية، الإمارات، مصر)، موجودة في `lib/ai/knowledge.ts`. كل ما تزوّدها وتدققها، التقييم بيبقى أذكى.
- **الخصوصية:** الاسم والإيميل والتليفون واللينكات وتاريخ الميلاد بيتشالوا قبل الإرسال (`lib/ai/redact.ts`).
- **الثبات:** لو الرد طلع ناقص بيعيد المحاولة، ولو الموديل الأساسي عليه ضغط بيجرّب `GEMINI_FALLBACK_MODEL`.
- التعليمات اللي بتتبعت للموديل موجودة في `lib/ai/cvReview.ts`.


## 7) أدوات مجانية (AT Tools)

- صفحة `/tools` فيها لينك تحميل AT Tools، وزرار يفتح واتساب برسالة جاهزة يكتب فيها الزائر الـ Machine ID بتاعه.
- لو لينك التحميل اتغيّر، حط الجديد في `NEXT_PUBLIC_AT_TOOLS_URL`.

## 8) إشعارات الإيميل (اختياري)

1. اعمل حساب مجاني على https://resend.com (3,000 إيميل في الشهر) وخد الـ API key، وحطه في `RESEND_API_KEY`.
2. حط إيميلك في `ADMIN_EMAIL`، علشان يوصلك إشعار بكل طلب اشتراك جديد.
3. علشان الإيميلات توصل للطلبة، لازم تربط دومين في Resend وتغيّر `EMAIL_FROM` لعنوان على الدومين ده، مثلًا `MEP LAB <noreply@meplab.net>`. من غير دومين، الإيميلات بتوصلك أنت بس.

الإيميلات اللي بتتبعت:
- **ليك:** لما يجي طلب اشتراك جديد.
- **للطالب:** لما توافق، ومعاه كود التفعيل.
- **للطالب:** لما ترفض، ومعاه السبب.

## 9) SEO

- `sitemap.xml` و `robots.txt` بيتعملوا أوتوماتيك، وصفحات الأدمن والحساب مستخبية عن جوجل.
- صورة المشاركة على فيسبوك ولينكدإن بتتعمل أوتوماتيك (`app/opengraph-image.tsx`).
- بعد الرفع: ضيف الموقع على Google Search Console وابعتله `https://YOUR-SITE/sitemap.xml`.


## 10) التفعيل الأونلاين من MEP LAB Player

- الـ API جاهز في الموقع: `POST /api/player/activate` و `POST /api/player/transfer`.
- تعديل الـ Player المطلوب موجود في `docs/PLAYER_ONLINE_ACTIVATION.md`. ابعته لوكيل البرمجة بتاع مشروع الـ Player.
- **أول خطوة في الملف:** الوكيل يطلّع `docs/LICENSE_FORMAT.md` من كود VidLock، فيه صيغة الرخصة الحقيقية. ابعته هنا علشان نحطه في `lib/license.ts`.
- في لوحة الأدمن هيظهرلك قسم **طلبات نقل رخصة لجهاز جديد**. لما توافق، الرخصة الجديدة بتتولّد، والطالب يوصله إيميل بيها.
- في صفحة تعديل الكورس، حط **لينك تحميل ملفات الكورس المشفّرة** (مثلًا من Cloudflare R2 أو Google Drive)، وكمان **معرّف الكورس في الـ Player** لو بتستخدم معرّف غير اللي في الموقع.


## 11) محرك MEP LAB ATS (الموديل الخاص بيك)

ده المحرك اللي بيقيّم الـ CV في صفحة `/cv-check`. بيشتغل **جوه متصفح الزائر**: من غير أي ذكاء اصطناعي خارجي، وبيانات الـ CV ما بتخرجش من جهازه. وبيشتغل بنفس طريقة أنظمة الـ ATS الحقيقية:

1. **قراءة الـ CV:** المهارات بتتعرف من **شبكة معرفة MEP** (`lib/ats/taxonomy.ts`)، اللي فيها 90 مهارة، ولكل واحدة كل مرادفاتها واختصاراتها. فمثلًا "heat load estimation" و"HAP" بيتفهموا إنهم حساب أحمال.
2. **ترتيب التخصصات:** بأوزان **متعلّمة** لكل تخصص ولكل سوق.
3. **المطابقة مع إعلان وظيفة**، زي الـ ATS بالظبط:
   - **فلاتر الاستبعاد:** سنين الخبرة، والمؤهل، والشهادات المطلوبة. لو فلتر منهم فشل، الدرجة بتتقفل على 35.
   - **المتطلبات:** الأساسية والإضافية.
   - **الكلمات الحرفية** اللي الـ ATS بيدوّر عليها.
   - **المسمى الوظيفي.**

**التدريب (الموديل بيتعلم لوحده):**
- كل يوم اتنين، الموديل بيتدرّب على إعلانات الوظايف اللي اتجمعت آخر 90 يوم (`lib/ats/train.ts`)، ومن غير ما تعمل حاجة:
  - بيعرف السوق بيطلب أنهي مهارات أكتر في كل تخصص وكل دولة، وبيعدّل الأوزان.
  - بيتعلم المرتبات الحقيقية من الإعلانات اللي فيها مرتب، وبيستخدمها بدل الأرقام الثابتة لما يبقى عنده 8 إعلانات أو أكتر.
  - بيطلّع **مصطلحات جديدة** أصحاب الشغل بيستخدموها ومش موجودة في شبكة المعرفة. ضيفها في `taxonomy.ts` علشان المحرك يفهمها.
- **لوحة الأدمن ← 🧠 ATS Model:** تشوف منها الإصدار، وعدد الإعلانات اللي اتدرّب عليها، والمرتبات المتعلّمة، والمصطلحات الجديدة. وفيها زرار "درّب الموديل دلوقتي".
- شغّل جزء **MEP LAB ATS models** اللي في آخر `schema.sql`.
- أول ما الموقع يترفع، الموديل بيشتغل بالنسخة الأولية (`0.1-prior`). كل ما قسم الوظايف يجمع إعلانات، الموديل بيبقى أدق.

**الدقة (على مجموعة اختبار مستقلة من 36 CV و12 إعلان):** التخصص 36/36، سنين الخبرة 36/36، المستوى 36/36، المهارات 228/228، فلاتر الاستبعاد 12/12. مجموعة الاختبار في `evalset/` وسكريبت القياس `tools/eval.ts` — شغّلهم بعد أي تعديل في المحرك.

**الصور والـ Scan:** الزائر يقدر يرفع صورة (JPG/PNG) أو PDF متصوّر، والموقع بيقرا النص بـ OCR عربي/إنجليزي جوه المتصفح (Tesseract، ملفاته في `public/ocr`، حوالي 13MB بتتحمّل أول مرة بس). بيظهر للزائر تنبيه إن أنظمة الـ ATS الحقيقية غالبًا ما تقراش الصور.

**تعديل الـ CV أوتوماتيك (مجانًا مرتين لكل جهاز):** زرار "عدّل الـ CV" بيعيد بناء الـ CV بصيغة ATS (عناوين قياسية، Summary، مهارات مجمّعة، نقاط خبرة بأفعال قوية، تواريخ موحّدة، وإزالة البيانات الشخصية الزيادة) ويطلّعه Word وPDF، مع نتيجة قبل/بعد. كله في المتصفح ومن غير ما يخترع أي معلومة. العدّاد في `lib/cv/export.ts` (`FREE_REWRITES`)، وبعد المرتين بيظهر زرار واتساب للتواصل معاك. الكود في `lib/cv/rebuild.ts`.

**Gemini بقى اختياري:** دوره دلوقتي الكتابة بس (Summary، وإعادة صياغة النقاط، وأسئلة الإنترفيو). التقييم كله من محركك.


## 12) أداة الـ CV كبوابة تسجيل (الإيميل)

- أي زائر يرفع CV، النتيجة **ما تظهرش** غير بعد ما يسجّل بإيميله (كود 6 أرقام) أو بحساب Google. وبعد النتيجة بيظهرله تعريف MEP LAB، وكورساتك، وزرار تحميل MEP LAB Player.
- كل استخدام بيتسجّل في **الإدارة ← 📧 Leads** (الإيميل، الاسم، التخصص، الدولة، نتيجة ATS)، مع تصدير CSV علشان تبعتلهم أخبار الكورسات. نص الـ CV نفسه **ما بيتخزنش** أبدًا.
- **مهم في Supabase:** علشان الإيميل يوصل فيه كود بدل لينك، من Authentication ← Email Templates ← **Magic Link**، خلّي النص فيه `{{ .Token }}`، مثلًا:
  `كود الدخول لموقع MEP LAB: {{ .Token }}` (ولو سيبت `{{ .ConfirmationURL }}` كمان، اللينك هيشتغل برضه ويرجّع الزائر لنتيجته).
- الخطة المجانية في Supabase بتبعت عدد محدود من الإيميلات في الساعة. لو الإقبال كبير، اربط مزوّد SMTP (Resend اللي عندك بيعمل كده) من Authentication ← SMTP Settings.
- **البروفايل:** التسجيل من الأداة بيبني بروفايل كامل للعضو (الاسم، الموبايل، التخصص، سنين الخبرة، الدولة)، وكل فحص بيحدّث فيه آخر نتيجة ATS والتخصص المكتشف وعدد مرات الفحص. العضو يشوفه ويعدّله من `/profile`، وأنت تشوفه في Leads. شغّل جزء **Member profile fields** في `schema.sql`.
- شغّل جزء **Leads** اللي في آخر `schema.sql`.

## 13) الكورسات الأربعة، "احنا مين"، والموقع للأعضاء بس

- `schema.sql` فيه الكورسات الأربعة جاهزة بمحتوى كامل (المنهج، هتتعلم إيه، لمين، المستوى، الساعات، البرامج): **Revit Mechanical** · **تصميم HVAC** · **تصميم Fire Fighting** · **تصميم Plumbing**. كلها `format = 'recorded'` فبتظهر شارة **كورس مسجّل** وجملة واضحة إنه مش لايف. عدّل الأسعار والمحتوى من **الإدارة ← الكورسات**.
- الرئيسية فيها في الآخر قسم **احنا مين؟** + المحاضر. النصوص في `lib/i18n.ts` (مفاتيح `about_*` و `instructor_*`).
- **الموقع للأعضاء:** الـ `middleware.ts` بيحوّل أي زائر من غير حساب لصفحة الدخول في: تفاصيل الكورسات، التحميل، الوظايف، الأدوات، الاشتراك، حسابي، بروفايلي، الإدارة. الرئيسية وقائمة الكورسات (كتيزر) وفحص الـ CV (له بوابة الإيميل بتاعته) مفتوحين.

## 14) التاسكات (الواجبات) والتصحيح

- شغّل جزء **Tasks** في `schema.sql` (جداول `course_tasks` و `task_submissions` + bucket خاص اسمه `tasks`).
- **الإدارة ← 📝 التاسكات:** تختار الكورس وتضيف تاسك من نوعين:
  - **ملف:** العضو يرفع (PDF / DOCX / XLSX / RVT / DWG / ZIP / صور — حتى 50 ميجا) ومعاه ملاحظة. يظهرلك في "في انتظار التصحيح" مع زرار تحميل الملف، تكتب الدرجة والملاحظات ← **حفظ الدرجة**. لو عايزه يعيد التسليم: **افتح لإعادة التسليم**.
  - **أسئلة اختيارية:** تكتب الأسئلة بصيغة بسيطة (السؤال في سطر، الاختيارات تحته بـ `-`، والصح بـ `*`، وسطر فاضي بين كل سؤال). بتتصحّح **أوتوماتيك** لحظة التسليم.
- **العضو:** من بروفايله أو من صفحة الكورس ← **التاسكات** (`/courses/<slug>/tasks`)، بس للي اشتراكه **مفعّل**. بيشوف الدرجة والملاحظات هناك وفي بروفايله، وبيوصله إيميل لما تصحّح (لو Resend متفعّل).

## 15) آخر CV للعضو

- بعد الفحص بيظهر زرار **احفظ الـ CV ده في حسابك** (برضاه — الفحص نفسه بيحصل على جهازه ومش بنخزّن نصه). الملف يتخزن في bucket خاص `cvs`، والعضو يحمّله أو يستبدله أو يمسحه من `/profile`.
- شغّل جزء **Last CV** في `schema.sql`. أنت كأدمن تقدر تشوف ملفات الـ CV من Supabase ← Storage ← `cvs`.

---

## دورة الطالب

1. يعمل حساب ← يفتح الكورس ← **اشترك دلوقتي**.
2. يحوّل المبلغ، ويرفع صورة التحويل، ويحط الـ **Machine Code** من MEP LAB Player.
3. الطلب يظهرلك في **/admin** ومعاه صورة التحويل.
4. تضغط **قبول** فالسيرفر يولّد كود التفعيل، أو **رفض** وتكتب السبب.
5. الكود يظهر للطالب في **حسابي** ومعاه زرار نسخ.
6. يتفرج على الكورس في MEP LAB Player، ويسلّم التاسكات من الموقع، وأنت تصحّحها من الإدارة.

## ⚠️ ربط كود التفعيل بـ MEP LAB Player

كل منطق توليد الكود موجود في ملف واحد: **`lib/license.ts`**.
الصيغة الحالية **مؤقتة** (HMAC-SHA256 من Machine Code + Course ID + تاريخ الانتهاء).
لازم تتبدل بنفس الخوارزمية اللي البرنامج بيتحقق بيها. ابعت ملفات توليد الرخص والتحقق منها من مشروع VidLock، وهتتعدّل في الملف ده بس.
